# Naming

- Python modules, files, and directories use `snake_case`.
- Paper windows use `t-2`; filenames and JSON keys use `t_minus_2` when a minus sign is unsuitable.
- Splits are `train`, `validation`, and `test`.
- Formal labels are `honest`, `dishonest`, and `invalid`.
- Generated directories should be placed under `outputs/`, which is ignored by Git.
- Stable source filenames do not include dates, `final`, `fixed`, or experiment-attempt suffixes.
